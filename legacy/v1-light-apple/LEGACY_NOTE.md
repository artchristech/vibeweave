# VibeWeave v1 — Apple Light Edition (Legacy)

This is the clean, premium, light-themed single-file version created in the "Apple just shipped a prompting product" design direction.

**Key characteristics of this version:**
- Extremely minimal, high-craft UI
- Light warm off-white theme
- Apple-like polish, generous whitespace, purposeful motion
- Focused onboarding-first experience with elegant inspiration cards
- One primary "Weave" action
- "Tune the weave" for progressive disclosure of advanced controls
- High-quality prompt synthesis logic

**Why it's legacy:**
We are now exploring a more ambitious visual + drag-and-drop composition experience featuring 3D game examples and dynamic prompt building from visual references.

**How to use this legacy version:**
Simply open `index.html` in a browser.
