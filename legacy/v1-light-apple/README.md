# VibeWeave

**Describe the game. Get the prompt that ships something good.**

A calm, premium, Apple-grade tool for serious game creators who use AI. Light. Minimal. Focused. The entire experience is designed to feel like a high-end native creative application — not another AI wrapper.

## What it is

- One beautiful place to turn a raw game idea into an elite, game-design-native prompt.
- Extremely low friction. You describe the fantasy. You optionally tune with tasteful controls. You weave.
- The output is production-ready for Claude, Cursor, Grok, or any strong model.
- Exports are seamless (CLAUDE.md, Cursor rules, etc.).

## Current version (single file)

Open `index.html` directly or serve it locally:

```bash
python3 -m http.server 0
```

No install. No account. No dark mode. Just a quiet, confident tool.

## Design direction

This version follows an explicit "Apple just shipped a prompting product" standard:

- Light, warm, generous aesthetic
- Ruthless reduction of visible controls
- Onboarding-first experience (beautiful input + elegant inspiration)
- One primary action
- Purposeful, restrained motion
- Result state that feels like receiving something valuable

See `DESIGN.md` for the full system.

## Philosophy

Most tools make you do the hard work of prompt engineering. VibeWeave does the hard work so you can stay in the creative flow.

The best prompt is the one that lets you start building the actual game faster, with better first results.

## Roadmap

- Real LLM integration with visible, editable reasoning stages
- Persistent personal taste profiles (your "DNA")
- Even more magical processing and result states
- Optional skill/CLI surface so you can invoke it from your agent
